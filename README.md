## Task tracker

Веб-приложение для управления проектами и задачами.

## Стек технологий

**Frontend:** JS React

**Backend:** Java Spring Boot

**База данных:** PostgreSQL

Для **управление пользователями** интегрировал открытое решение  **Keycloak**
